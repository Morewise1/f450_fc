# ESC 无桨测试

所有步骤必须拆下四个桨叶。波形验证阶段不要接电机动力电源，只连接飞控、逻辑分析仪或示波器，并确保共地。

## A. 纯 PWM 波形

1. 上电后不授予输出许可，确认四路立即为 1000 us。
2. 尝试调用 `BSP_EscPwm_WriteUs(M1, 1500)`，接口应返回未就绪，M1 仍为 1000 us。
3. 对非法 motor ID 写 1500 us，确认四路 CCR 均未变化。
4. 在专用测试固件中调用 `BSP_EscPwm_SetOutputEnabled(true)`。
5. 分别输出 1000、1500、2000 us，用示波器测量高电平宽度。
6. 调用 `BSP_EscPwm_StopAll()`，确认四路立即恢复 1000 us，输出许可同时关闭。
7. 再次写入 1500 us，确认仍被拒绝。

1 MHz 计数器的分辨率为 1 us；2 MHz 为 0.5 us。实测误差应在少量 timer tick 内。

## B. 1000/1500/2000 us 验证

假设定时器计数频率为 1 MHz、PWM 帧率为 400 Hz：

```text
周期约 2500 us
1000 us -> CCR 1000，占空比约 40%
1500 us -> CCR 1500，占空比约 60%
2000 us -> CCR 2000，占空比约 80%
```

若计数频率不是 1 MHz，应按 `Docs/esc_pwm_hal_integration.md` 的公式计算 CCR。判断标准是高电平时间，不是固定 CCR 数字。

## C. 四路物理映射

1. 每次只修改 M1、M2、M3 或 M4 中的一路。
2. 确认波形只出现在对应物理引脚。
3. 按 `motor_layout.md` 核对电机编号、位置和旋向。
4. 通道顺序错误时只修改 `fc_board.h`，不要在 mixer 中临时交换。

## D. 接 ESC 和电机

1. 保持拆桨并固定机架，飞控与 ESC 必须共地。
2. 先持续发送 1000 us，再接通 ESC 动力电源并等待上电提示。
3. 每次只测试一个电机，短时发送 `FC_ESC_IDLE_US`，默认 1100 us。
4. 核对电机编号和旋向后立即调用 `BSP_EscPwm_StopAll()`。
5. 断开遥控器或触发急停，确认输出恢复 1000 us。

2000 us 只在不接电机动力时做波形验证。即使拆桨，也不要让 2212 电机长时间满油门空载运行。
