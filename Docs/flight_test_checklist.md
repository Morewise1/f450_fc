# Flight Test Checklist

当前 stub 版本禁止装桨飞行。进入飞行测试前至少完成：

- ARM GCC 工程可重复编译，零 warning。
- 1 ms tick 和任务频率通过逻辑分析或计时验证。
- BMI088 双芯片 ID、单位、轴方向、静止校准验证完成。
- i-BUS 通道、超时和 failsafe 验证完成。
- 四路 ESC 1000-2000 us 波形验证完成。
- 若启用电池监测，ADC 必须用万用表标定且未知电压不能解锁；若关闭监测，必须使用外部低压告警并限制飞行时间。
- 无桨电机编号、旋向和急停验证完成。
- 拆桨观察遥控差速：正 roll 为 M3/M4 高于 M1/M2，正 pitch 为 M1/M4 高于 M2/M3，正 yaw 为 M1/M3 高于 M2/M4。
- 遥控回中后手动倾斜机体，PID 必须给出阻止该倾斜的反向电机差速；任一轴助推倾倒都必须立即断电并修正轴符号或混控符号。
- PID 增益只在限位架上从低到高调整，当前 `fc_params.h` 数值不是免调参数。
- 装桨测试至少两人在场，并保留立即断电手段。
